# 1.2 Installation Guide

## Official Channels and System Requirements

Only download FyAgent from **[GitHub Releases](https://github.com/NongHua123/fyagent/releases)** or the [project source repository](https://github.com/NongHua123/fyagent). No separate FyAgent website is established by this repository; treat any site or client that asks for payment, top-ups, or login credentials as unofficial.

| System  | Minimum Version              | Architecture                        |
| ------- | ---------------------------- | ----------------------------------- |
| Windows | Windows 10 or later          | x64 / ARM64                         |
| macOS   | macOS 12 (Monterey) or later | Intel (x64) / Apple Silicon (arm64) |
| Linux   | See distribution notes below | x64 / ARM64                         |

## Prerequisites

### Install Node.js

The CLI tools managed by FyAgent (Claude Code, Codex, Gemini CLI) require a Node.js environment.

**Recommended version**: Node.js 18 LTS or higher

#### Windows

1. Visit the [Node.js official website](https://nodejs.org/)

2. Download the LTS version installer

3. Run the installer and follow the prompts

4. Verify installation:

```bash
node --version
npm --version
```

#### macOS

```bash
# Install with Homebrew
brew install node

# Or use nvm (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# Or use nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### Install CLI Tools

#### Claude Code

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install claude-code
```

**Option 2: npm**

```bash
npm install -g @anthropic-ai/claude-code
```

#### Codex

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install codex
```

**Option 2: npm**

```bash
npm install -g @openai/codex
```

#### Gemini CLI

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install gemini-cli
```

**Option 2: npm**

```bash
npm install -g @google/gemini-cli
```

## Windows

### Installer

1. Visit the [Releases page](https://github.com/NongHua123/fyagent/releases)
2. Download `FyAgent-X.Y.Z-Windows-x64-setup.exe` or
   `FyAgent-X.Y.Z-Windows-arm64-setup.exe` for your architecture
3. Double-click to run the installer
4. Follow the prompts to complete installation

These are per-machine NSIS setup programs. FyAgent does not publish an MSI or
Windows Portable ZIP. Before continuing, verify the exact Release's signing
status, SHA-256, source SHA, and attestation; an explicitly `NotSigned` setup can
trigger Windows trust warnings.

## macOS

### Download from GitHub Releases

1. Download `FyAgent-X.Y.Z-macOS.dmg` (recommended) or `FyAgent-X.Y.Z-macOS.zip`
2. Open the DMG, or extract the zip to get `FyAgent.app`
3. Drag it to the Applications folder

### Current Signing and Notarization Status

The current formal macOS workflow produces an unsigned universal app. It is
**not signed with an Apple Developer ID** and is **not notarized by Apple**, so
Gatekeeper may block the first launch even when the downloaded file is intact.
Before opening it, verify the exact Release's SHA-256, source SHA, and
attestation.

### If Gatekeeper Blocks the First Launch

1. Try to open `FyAgent.app` once from the Applications folder, then dismiss
   the warning.
2. Open **System Settings → Privacy & Security**.
3. In the **Security** section, find the message about `FyAgent.app` and click
   **Open Anyway**.
4. Authenticate with your password or Touch ID when macOS asks.
5. Confirm **Open** only after checking that the app came from the official
   FyAgent Release and that its verification evidence matches your download.

Do not disable Gatekeeper or remove the file's quarantine attribute. Those
workarounds weaken macOS protection beyond this one verified app.

## Linux

### Formal Release Assets

| Format   | x64 asset                             | ARM64 asset                          |
| -------- | ------------------------------------- | ------------------------------------ |
| AppImage | `FyAgent-X.Y.Z-Linux-x86_64.AppImage` | `FyAgent-X.Y.Z-Linux-arm64.AppImage` |
| DEB      | `FyAgent-X.Y.Z-Linux-x86_64.deb`      | `FyAgent-X.Y.Z-Linux-arm64.deb`      |
| RPM      | `FyAgent-X.Y.Z-Linux-x86_64.rpm`      | `FyAgent-X.Y.Z-Linux-arm64.rpm`      |

### Debian / Ubuntu

1. Download `FyAgent-X.Y.Z-Linux-x86_64.deb` or `FyAgent-X.Y.Z-Linux-arm64.deb` for your architecture
2. Run the command matching your architecture:

```bash
# x64
sudo dpkg -i FyAgent-X.Y.Z-Linux-x86_64.deb

# ARM64
sudo dpkg -i FyAgent-X.Y.Z-Linux-arm64.deb

# If there are dependency issues
sudo apt-get install -f
```

### Fedora / RHEL / RPM-Compatible Distributions

1. Download `FyAgent-X.Y.Z-Linux-x86_64.rpm` or
   `FyAgent-X.Y.Z-Linux-arm64.rpm` for your architecture.
2. Run the command matching your architecture:

```bash
# x64
sudo dnf install ./FyAgent-X.Y.Z-Linux-x86_64.rpm

# ARM64
sudo dnf install ./FyAgent-X.Y.Z-Linux-arm64.rpm
```

### AppImage (Universal)

1. Download `FyAgent-X.Y.Z-Linux-x86_64.AppImage` or `FyAgent-X.Y.Z-Linux-arm64.AppImage` for your architecture
2. Add execute permission and run the commands matching your architecture:

```bash
# x64
chmod +x FyAgent-X.Y.Z-Linux-x86_64.AppImage
./FyAgent-X.Y.Z-Linux-x86_64.AppImage

# ARM64
chmod +x FyAgent-X.Y.Z-Linux-arm64.AppImage
./FyAgent-X.Y.Z-Linux-arm64.AppImage
```

## Verify Installation

After installation, launch FyAgent:

1. The app window displays correctly
2. A FyAgent icon appears in the system tray
3. The app switcher shows enabled managed apps, and you can switch to the target app panel

## Updating FyAgent

FyAgent does not include an in-app auto-updater. To update, open the real
[`NongHua123/fyagent` Releases page](https://github.com/NongHua123/fyagent/releases),
select the asset for your platform and architecture, and follow that release's
installation notes. For macOS, the current formal workflow is Developer ID
unsigned and not notarized; verify the evidence published for the exact build
before installing it.

## Uninstall

### Windows

- Uninstall via "Settings > Apps"
- Or run the uninstaller in the installation directory

### macOS

- Move `FyAgent.app` to Trash
- Optional: Delete the configuration directory `~/.fyagent/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove fyagent

# Fedora/RHEL
sudo dnf remove fyagent

```
