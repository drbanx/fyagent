# 1.2 インストールガイド

## 公式チャネルとシステム要件

FyAgent は **[GitHub Releases](https://github.com/NongHua123/fyagent/releases)** または [プロジェクトのソースリポジトリ](https://github.com/NongHua123/fyagent) からのみ入手してください。このリポジトリでは FyAgent の別サイトは定義されていません。支払い、チャージ、またはログイン情報の入力を求めるサイトやクライアントは非公式として扱ってください。

| システム | 最低バージョン                       | アーキテクチャ                      |
| -------- | ------------------------------------ | ----------------------------------- |
| Windows  | Windows 10 以上                      | x64 / ARM64                         |
| macOS    | macOS 12 (Monterey) 以上             | Intel (x64) / Apple Silicon (arm64) |
| Linux    | 下記ディストリビューション説明を参照 | x64 / ARM64                         |

## 前提条件

### Node.js のインストール

FyAgent が管理する CLI ツール（Claude Code、Codex、Gemini CLI）には Node.js 環境が必要です。

**推奨バージョン**：Node.js 18 LTS 以上

#### Windows

1. [Node.js 公式サイト](https://nodejs.org/) にアクセス

2. LTS バージョンのインストーラーをダウンロード

3. インストーラーを実行し、指示に従ってインストール

4. インストールの確認：

```bash
node --version
npm --version
```

#### macOS

```bash
# Homebrew でインストール
brew install node

# または nvm を使用（推奨）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# または nvm を使用
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### CLI ツールのインストール

#### Claude Code

**方法 1：Homebrew（macOS 推奨）**

```bash
brew install claude-code
```

**方法 2：npm**

```bash
npm install -g @anthropic-ai/claude-code
```

#### Codex

**方法 1：Homebrew（macOS 推奨）**

```bash
brew install codex
```

**方法 2：npm**

```bash
npm install -g @openai/codex
```

#### Gemini CLI

**方法 1：Homebrew（macOS 推奨）**

```bash
brew install gemini-cli
```

**方法 2：npm**

```bash
npm install -g @google/gemini-cli
```

## Windows

### インストーラー方式

1. [Releases ページ](https://github.com/NongHua123/fyagent/releases) にアクセス
2. アーキテクチャに合わせて `FyAgent-X.Y.Z-Windows-x64-setup.exe` または
   `FyAgent-X.Y.Z-Windows-arm64-setup.exe` をダウンロード
3. インストーラーをダブルクリックして実行
4. 指示に従ってインストール

これらは全マシン向け NSIS setup です。FyAgent は MSI や Windows ポータブル
ZIP を公開しません。続行前に、対象 Release の署名状態、SHA-256、source SHA、
attestation を確認してください。明示的に `NotSigned` の setup では Windows の
信頼警告が表示される場合があります。

## macOS

### GitHub Releases からダウンロード

1. `FyAgent-X.Y.Z-macOS.dmg`（推奨）または `FyAgent-X.Y.Z-macOS.zip` をダウンロード
2. DMG を開く、または zip を展開して `FyAgent.app` を取得
3. 「アプリケーション」フォルダにドラッグ

### 現在の署名と公証の状態

現在の正式な macOS リリースワークフローでは、未署名のユニバーサルアプリを
生成します。**Apple Developer ID では署名されておらず**、**Apple の公証も受けて
いません**。そのため、ダウンロードしたファイルが完全でも、初回起動を Gatekeeper が
ブロックする場合があります。開く前に、対象 Release の SHA-256、source SHA、
attestation を確認してください。

### Gatekeeper が初回起動をブロックした場合

1. まず「アプリケーション」フォルダから `FyAgent.app` を一度開き、警告を閉じます。
2. 「**システム設定 → プライバシーとセキュリティ**」（System Settings → Privacy
   & Security）を開きます。
3. 「セキュリティ」セクションで `FyAgent.app` に関するメッセージを見つけ、
   「**このまま開く**」をクリックします。英語表記は `Open Anyway` です。
4. macOS から求められたら、パスワードまたは Touch ID で認証します。
5. アプリが FyAgent の公式 Release から取得したもので、検証証拠がダウンロードした
   ファイルと一致することを確認してから、「開く」を確定します。

Gatekeeper を無効にしたり、ファイルの quarantine（隔離）属性を削除したりしないで
ください。これらの回避策は、この確認済みアプリ以外に対する macOS の保護も弱めます。

## Linux

### 正式な Release アセット

| 形式     | x64 アセット                          | ARM64 アセット                       |
| -------- | ------------------------------------- | ------------------------------------ |
| AppImage | `FyAgent-X.Y.Z-Linux-x86_64.AppImage` | `FyAgent-X.Y.Z-Linux-arm64.AppImage` |
| DEB      | `FyAgent-X.Y.Z-Linux-x86_64.deb`      | `FyAgent-X.Y.Z-Linux-arm64.deb`      |
| RPM      | `FyAgent-X.Y.Z-Linux-x86_64.rpm`      | `FyAgent-X.Y.Z-Linux-arm64.rpm`      |

### Debian / Ubuntu

1. アーキテクチャに合わせて `FyAgent-X.Y.Z-Linux-x86_64.deb` または `FyAgent-X.Y.Z-Linux-arm64.deb` をダウンロード
2. アーキテクチャに合うコマンドを実行：

```bash
# x64
sudo dpkg -i FyAgent-X.Y.Z-Linux-x86_64.deb

# ARM64
sudo dpkg -i FyAgent-X.Y.Z-Linux-arm64.deb

# 依存関係に問題がある場合
sudo apt-get install -f
```

### Fedora / RHEL / RPM 互換ディストリビューション

1. アーキテクチャに合わせて `FyAgent-X.Y.Z-Linux-x86_64.rpm` または
   `FyAgent-X.Y.Z-Linux-arm64.rpm` をダウンロード
2. アーキテクチャに合うコマンドを実行：

```bash
# x64
sudo dnf install ./FyAgent-X.Y.Z-Linux-x86_64.rpm

# ARM64
sudo dnf install ./FyAgent-X.Y.Z-Linux-arm64.rpm
```

### AppImage（汎用）

1. アーキテクチャに合わせて `FyAgent-X.Y.Z-Linux-x86_64.AppImage` または `FyAgent-X.Y.Z-Linux-arm64.AppImage` をダウンロード
2. アーキテクチャに合う権限付与・起動コマンドを実行：

```bash
# x64
chmod +x FyAgent-X.Y.Z-Linux-x86_64.AppImage
./FyAgent-X.Y.Z-Linux-x86_64.AppImage

# ARM64
chmod +x FyAgent-X.Y.Z-Linux-arm64.AppImage
./FyAgent-X.Y.Z-Linux-arm64.AppImage
```

## インストールの確認

インストール完了後、FyAgent を起動します：

1. アプリウィンドウが正常に表示される
2. システムトレイに FyAgent のアイコンが表示される
3. アプリ切り替えに有効化された管理対象アプリが表示され、目的のアプリパネルへ切り替えられる

## FyAgent の更新

FyAgent にはアプリ内自動アップデーターはありません。更新する場合は、実在する
[`NongHua123/fyagent` Releases ページ](https://github.com/NongHua123/fyagent/releases)
を開き、使用中のプラットフォームとアーキテクチャに合う成果物を選び、その Release
のインストール手順に従ってください。現在の正式な macOS リリースワークフローは
Developer ID で署名されておらず、公証も受けていません。インストール前に対象
ビルドについて公開された検証証拠を確認してください。

## アンインストール

### Windows

- 「設定 → アプリ」からアンインストール
- またはインストールディレクトリのアンインストーラーを実行

### macOS

- `FyAgent.app` をゴミ箱に移動
- オプション：設定ディレクトリ `~/.fyagent/` を削除

### Linux

```bash
# Debian/Ubuntu
sudo apt remove fyagent

# Fedora/RHEL
sudo dnf remove fyagent

```
