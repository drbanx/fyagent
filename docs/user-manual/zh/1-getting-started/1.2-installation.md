# 1.2 安装指南

## 官方渠道与系统要求

请只从 **[GitHub Releases](https://github.com/NongHua123/fyagent/releases)** 或 [项目源码仓库](https://github.com/NongHua123/fyagent) 获取 FyAgent。本仓库尚未确立独立的 FyAgent 官方网站；任何要求付费、充值或索取登录凭据的网站或客户端都应视为非官方渠道。

| 系统    | 最低版本                   | 架构                                |
| ------- | -------------------------- | ----------------------------------- |
| Windows | Windows 10 及以上          | x64 / ARM64                         |
| macOS   | macOS 12 (Monterey) 及以上 | Intel (x64) / Apple Silicon (arm64) |
| Linux   | 见下方发行版说明           | x64 / ARM64                         |

## 前置要求

### 安装 Node.js

FyAgent 管理的 CLI 工具（Claude Code、Codex、Gemini CLI）需要 Node.js 环境。

**推荐版本**：Node.js 18 LTS 或更高版本

#### Windows

1. 访问 [Node.js 官网](https://nodejs.org/)

2. 下载 LTS 版本安装包

3. 运行安装程序，按提示完成安装

4. 验证安装：

```bash
node --version
npm --version
```

#### macOS

```bash
# 使用 Homebrew 安装
brew install node

# 或使用 nvm（推荐）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# 或使用 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### 安装 CLI 工具

#### Claude Code

**方式一：Homebrew（macOS 推荐）**

```bash
brew install claude-code
```

**方式二：npm**

```bash
npm install -g @anthropic-ai/claude-code

# 国内用户如下载慢，使用镜像源
npm install -g @anthropic-ai/claude-code --registry=https://registry.npmmirror.com
```

#### Codex

**方式一：Homebrew（macOS 推荐）**

```bash
brew install codex
```

**方式二：npm**

```bash
npm install -g @openai/codex

# 国内用户如下载慢，使用镜像源
npm install -g @openai/codex --registry=https://registry.npmmirror.com
```

#### Gemini CLI

**方式一：Homebrew（macOS 推荐）**

```bash
brew install gemini-cli
```

**方式二：npm**

```bash
npm install -g @google/gemini-cli

# 国内用户如下载慢，使用镜像源
npm install -g @google/gemini-cli --registry=https://registry.npmmirror.com
```

> 💡 **提示**：如果经常遇到下载慢的问题，可以全局设置镜像源：
>
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

## Windows

### 安装包方式

1. 访问 [Releases 页面](https://github.com/NongHua123/fyagent/releases)
2. 根据架构下载 `FyAgent-X.Y.Z-Windows-x64-setup.exe` 或
   `FyAgent-X.Y.Z-Windows-arm64-setup.exe`
3. 双击运行安装程序
4. 按提示完成安装

这些是全机器 NSIS 安装程序。FyAgent 不再发布 MSI 或 Windows 绿色版 ZIP。
继续前请核对具体 Release 的签名状态、SHA-256、源码 SHA 和 attestation；明确为
`NotSigned` 的安装程序会触发 Windows 信任提示。不要关闭 SmartScreen、移除下载
来源标记或削弱组织管理的安全策略。

## macOS

### 从 GitHub Releases 下载

1. 下载 `FyAgent-X.Y.Z-macOS.dmg`（推荐）或 `FyAgent-X.Y.Z-macOS.zip`
2. 打开 DMG，或解压 zip 得到 `FyAgent.app`
3. 拖动到「应用程序」文件夹

### 当前签名与公证状态

当前正式 macOS 发布工作流使用无证书身份的 ad-hoc 签名封装完整的通用应用，
并在打包前验证该签名。ZIP 和 DMG 内含同一应用，DMG 容器本身未签名。
它未使用 Apple Developer ID 签名，也未经 Apple 公证；ad-hoc 签名不提供证书背书的
发布者身份或 Apple 信任。
因此，即使下载文件完整，Gatekeeper 仍可能拦截首次启动。打开前请核对具体
Release 的 SHA-256、源码 SHA 和 attestation。

### Gatekeeper 拦截首次启动时

1. 先从「应用程序」文件夹尝试打开一次 `FyAgent.app`，然后关闭警告。
2. 打开「**系统设置 → 隐私与安全性**」（System Settings → Privacy &
   Security）。
3. 在「安全性」区域找到关于 `FyAgent.app` 的提示，点击「**仍要打开**」。按钮的
   英文名称是 `Open Anyway`。
4. macOS 提示时，使用密码或 Touch ID 认证。
5. 确认应用来自 FyAgent 官方 Release，且验证证据与下载文件一致后，再确认
   「打开」。

不要关闭 Gatekeeper，也不要移除文件的 quarantine（隔离）属性；这些做法会削弱
macOS 对其他下载文件的保护。

## Linux

### 正式 Release 资产

| 格式     | x64 资产                              | ARM64 资产                           |
| -------- | ------------------------------------- | ------------------------------------ |
| AppImage | `FyAgent-X.Y.Z-Linux-x86_64.AppImage` | `FyAgent-X.Y.Z-Linux-arm64.AppImage` |
| DEB      | `FyAgent-X.Y.Z-Linux-x86_64.deb`      | `FyAgent-X.Y.Z-Linux-arm64.deb`      |
| RPM      | `FyAgent-X.Y.Z-Linux-x86_64.rpm`      | `FyAgent-X.Y.Z-Linux-arm64.rpm`      |

### Debian / Ubuntu

1. 根据架构下载 `FyAgent-X.Y.Z-Linux-x86_64.deb` 或 `FyAgent-X.Y.Z-Linux-arm64.deb`
2. 运行与架构匹配的命令：

```bash
# x64
sudo dpkg -i FyAgent-X.Y.Z-Linux-x86_64.deb

# ARM64
sudo dpkg -i FyAgent-X.Y.Z-Linux-arm64.deb

# 如果有依赖问题
sudo apt-get install -f
```

### Fedora / RHEL / RPM 兼容发行版

1. 根据架构下载 `FyAgent-X.Y.Z-Linux-x86_64.rpm` 或
   `FyAgent-X.Y.Z-Linux-arm64.rpm`
2. 运行与架构匹配的命令：

```bash
# x64
sudo dnf install ./FyAgent-X.Y.Z-Linux-x86_64.rpm

# ARM64
sudo dnf install ./FyAgent-X.Y.Z-Linux-arm64.rpm
```

### AppImage（通用）

1. 根据架构下载 `FyAgent-X.Y.Z-Linux-x86_64.AppImage` 或 `FyAgent-X.Y.Z-Linux-arm64.AppImage`
2. 运行与架构匹配的授权和启动命令：

```bash
# x64
chmod +x FyAgent-X.Y.Z-Linux-x86_64.AppImage
./FyAgent-X.Y.Z-Linux-x86_64.AppImage

# ARM64
chmod +x FyAgent-X.Y.Z-Linux-arm64.AppImage
./FyAgent-X.Y.Z-Linux-arm64.AppImage
```

## 验证安装

安装完成后，启动 FyAgent：

1. 应用窗口正常显示
2. 系统托盘出现 FyAgent 图标
3. 应用切换器中能看到已启用的受管应用，并能切换到目标应用面板

## 更新 FyAgent

FyAgent 不包含应用内自动更新器。需要更新时，请打开真实的
[`NongHua123/fyagent` Releases 页面](https://github.com/NongHua123/fyagent/releases)，
选择与你的平台和架构对应的产物，并按该 Release 的安装说明操作。当前正式 macOS
应用仅有无证书身份的 ad-hoc 签名，DMG 容器本身未签名；两者都不提供 Developer ID
或公证信任。安装前应核对具体构建公开的验证证据。

## 卸载

### Windows

- 通过「设置 → 应用」卸载
- 或运行安装目录下的卸载程序

### macOS

- 将 `FyAgent.app` 移到废纸篓
- 可选：删除配置目录 `~/.fyagent/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove fyagent

# Fedora/RHEL
sudo dnf remove fyagent

```
